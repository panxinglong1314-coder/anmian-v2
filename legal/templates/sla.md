# 服务级别协议 SLA · 知眠企业版

> 草稿 v0.1 — 服务合同附件 2

## 1. 可用性承诺

### 1.1 月度可用性 ≥ 99.5%

可用性 = (月度总时间 - 计划外停机时间) / 月度总时间

**计划外停机**不包括:
- 计划内维护(乙方提前 48 小时书面通知)
- 不可抗力(地震、停电、互联网骨干故障)
- 第三方依赖服务故障(云供应商、DeepSeek 等)
- 甲方原因(账号配置错误、错误 API 用法)

### 1.2 故障响应时间

| 严重程度 | 定义 | 首次响应 | 解决目标 |
|---|---|---|---|
| P0 严重 | 全平台不可用 | 30 分钟内 | 4 小时内 |
| P1 重大 | 关键功能不可用(如 HR 后台无法登录) | 2 小时内 | 1 工作日内 |
| P2 一般 | 部分功能异常,有 workaround | 1 工作日内 | 5 工作日内 |
| P3 轻微 | 不影响使用的 bug、文案错误 | 5 工作日内 | 下次例行更新 |

## 2. 性能承诺

| 接口 | 响应时间(P95) |
|---|---|
| Chat 对话首字节 | < 2 秒 |
| 团队聚合 API | < 3 秒 |
| 月度 PDF 报告下载 | < 10 秒 |
| Admin 页面加载 | < 2 秒 |

## 3. 故障赔偿(SLA 违约)

### 3.1 可用性低于承诺时的服务时长补偿

| 月度可用性 | 补偿 |
|---|---|
| < 99.5% 但 ≥ 99.0% | 当月服务费 10% 抵扣 |
| < 99.0% 但 ≥ 95.0% | 当月服务费 25% 抵扣 |
| < 95.0% | 当月服务费 100% 抵扣 + 客户可单方面终止合同 |

补偿方式:抵扣下月账单。

### 3.2 P0/P1 故障未在 SLA 时限解决的赔偿

每超时 1 小时,赔偿当年服务费的 0.1%,累计上限当年服务费 10%。

## 4. 客户支持

### 4.1 工作时间
- 周一至周五 09:00-18:00(北京时间)
- 节假日休息
- 紧急情况(P0/P1)24x7 可触达

### 4.2 联系方式
- 邮件:support@sleepai.chat
- 微信:[企业微信群] / 客户经理直联
- 紧急电话:[客户经理手机]

## 5. 通知

### 5.1 计划内维护
乙方提前 **48 小时**书面通知,通常在周末凌晨进行,持续不超过 4 小时。

### 5.2 安全事件
个人数据泄露:**24 小时**内通知
重大安全漏洞:**48 小时**内通知 + 修复计划

## 6. 报表

每月 5 日前,乙方向甲方提供上月 SLA 报告:
- 实际可用性百分比
- 故障次数(按 P0/P1/P2/P3 分级)
- 平均响应时间 / 平均解决时间
- 是否需要 SLA 抵扣
