## 走签合同的流程

1. **NDA** 先签(可用客户的标准模板,或本目录 `templates/nda.md`(待补))
2. 销售用 `service_agreement.md` + `dpa_china.md` 给客户报价/讨论
3. 客户法务反馈,**律师参与**修改条款
4. 双方签字
5. HR 在 onboarding 时给员工签 `employee_consent.md`(系统注册流程会强制弹出)
6. 上线
7. 客户法务问"系统怎么保证 HR 看不到个人"→ 提供:
   - `architecture_notes.md`(数据流图 + k-anonymity 阈值证据)
   - 系统审计日志接口(`/api/v1/admin/audit/*`,待加)

## 重要决策点(给律师沟通用)

1. **责任边界**:知眠是 AI 陪伴工具(类似 Woebot / Wysa),**不构成医疗服务**。
   - 法律依据:《精神卫生法》第 23 条 "心理咨询人员不得从事心理治疗或者精神障碍诊断、治疗"
   - 合同必须明确:服务范围、医疗免责、危机响应是引导专业资源而不是"诊治"

2. **HR 不通知机制**:HR 不收到具体员工危机事件的法律意义
   - 我们的立场:这是法律保护(避免"看到却未干预"的过失责任),不是产品缺陷
   - 合同里这是**明确条款**,要客户认可

3. **数据所有权**:
   - 员工对话 / 睡眠数据:属于**员工个人**,客户(HR)无权获取个体级别
   - 聚合统计:属于**客户企业**,我们提供给 HR 是履约
   - 我们的去标识化样本(可能用于产品优化):需员工同意书明确授权

4. **离职处理**:
   - HR 1 键 unbind → 员工归属企业账户解除
   - 员工个人对话/睡眠记录**保留**在员工账户(可转 B2C 个人付费)
   - 历史聚合数据可保留**12 个月**做趋势对比,但不能链回个人

5. **争议解决**:仲裁 vs 法院,适用法律。模板里默认仲裁(上海仲裁委员会)。
